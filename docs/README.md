# Overview

> These docs were imported from the GitHub wiki for users on the
> [`legacy-conf`](https://github.com/uhs-robert/hyprvim/tree/legacy-conf)
> branch.
>
> They describe the legacy Hyprland `.conf` setup, not the current Lua
> configuration format.

**HyprVim** brings the power of Vim keybindings and motions to your entire Hyprland desktop environment.

Built on Hyprland’s native submap system, uses standard keyboard shortcut macros to emulate Vim-style navigation and text editing.

This Wiki documents how to use HyprVim, configuration, all available keybindings and commands, and how to use those commands outside of HyprVim as well. Think of this as your man page.

## Getting Started

Please follow the [installation steps from the readme](https://github.com/uhs-robert/hyprvim/tree/legacy-conf#-installation)

Then get started with [Configuration](Configuration.md).

From there, work your way through [Basics](Basics.md), [Modes](Modes.md), [Advanced](Advanced.md), and [Tips and Tricks](Tips-and-Tricks.md).
